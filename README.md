# ☕ 브릿지 카페 홍보물 자동 만들기

매장 사진과 가게 정보를 넣고 한 번 실행하면, 인스타그램 사진과 채널별 홍보 문구를 한꺼번에 만들어 주는 파이썬 프로그램입니다.

## 만들어 주는 것

| 결과물 | 내용 |
| --- | --- |
| 인스타그램 사진 | 1080 × 1080 정사각형, 가운데 기준으로 잘라서 찌그러짐 없음, 오른쪽 아래에 로고 |
| 인스타그램 문구 | 감성형 / 정보형 / 이벤트형 3가지, 해시태그 10개 |
| 네이버 블로그 글 | 문단을 나눈 긴 글 1개, 해시태그 없음 |
| 카카오톡 공지 | 단골손님용 3줄 공지 1개 |

- 원본 사진은 바꾸지 않습니다.
- 문구는 사장님이 직접 쓴 글의 말투(짧은 문장, 한 줄에 한 문장, 과장 없이)에 맞춰 만들어집니다.

## 폴더 구조

```
홍보자동화/
├── 인스타변환.py       # 사진 변환 + 로고 넣기 + 홍보 문구 만들기
├── 홍보물만들기.bat     # 더블클릭으로 실행하는 파일
├── 로고.ico            # 바탕화면 아이콘 그림
├── 사용설명서.txt       # 매주 사용하는 방법 (비개발자용)
├── 자료/               # 넣는 곳
│   ├── (매장 사진들).jpg / .png
│   ├── 로고.png        # 사진에 붙는 로고 (로고.jpg가 있으면 그것을 먼저 사용)
│   ├── 가게 정보.txt    # 가게 소개와 이번 주 홍보 내용
│   └── 내 말투.txt      # 말투 참고용 글
└── 완성/               # 결과가 생기는 곳
    ├── 오늘날짜_01.jpg …
    └── 홍보문구.txt
```

## 준비물

- Windows
- Python 3.12 이상
- Pillow (사진 처리 도구)

```bash
py -m pip install pillow
```

## 실행 방법

`홍보물만들기.bat`을 더블클릭합니다. 바탕화면 바로가기를 만들어 두면 더 편합니다. 다 끝나면 `완성` 폴더가 저절로 열립니다.

명령어로 실행하려면 이렇게 합니다.

```bash
py 인스타변환.py
```

## 매주 바꾸는 것

1. `자료` 폴더의 지난주 사진을 치우고, 이번 주 사진을 넣습니다. `로고.png`는 그대로 둡니다.
2. `자료/가게 정보.txt`에서 `이번 주 홍보할 것:` 아래 줄만 바꿉니다.

```
이번 주 홍보할 것:
- 신메뉴 '흑임자 라떼' 5,500원, 국산 흑임자를 직접 갈아서 넣음, 고소하고 달지 않음
- 오전 11시 이전 방문 시 아메리카노 500원 할인
```

- 줄 맨 앞에 `-`를 붙입니다.
- 신메뉴는 `- 신메뉴 '메뉴이름' 가격, 설명, 설명` 모양으로 씁니다. 메뉴 이름은 작은따옴표로 감쌉니다.
- 할인·행사 줄에는 `할인`, `증정`, `무료`, `이벤트` 중 하나가 들어가게 씁니다.
- 설명은 `넣음`, `않음`처럼 짧게 쓰면 `넣습니다`, `않습니다`로 바꿔 줍니다.

자세한 방법과 안 될 때 확인할 것은 [사용설명서.txt](사용설명서.txt)에 있습니다.

## 알아 두면 좋은 점

- 같은 날 다시 실행하면 사진은 다음 번호부터 이어서 저장됩니다. 이전 사진은 덮어쓰지 않습니다.
- `홍보문구.txt`는 실행할 때마다 새 내용으로 바뀝니다.
- 로고나 가게 정보 파일이 없으면 그 단계만 건너뛰고, 오류 없이 나머지를 만듭니다.
- 문구는 정해진 문장 틀에 가게 정보를 끼워 넣는 방식이라 인터넷이나 AI 가입이 필요 없습니다. 올리기 전에 한 번 읽어 보고 다듬어 주세요.
